## 📌 Project Overview

**DataMind Studio** is an AI-inspired Dataset Intelligence Dashboard designed for Data Science students, researchers, and analysts. It simplifies Exploratory Data Analysis (EDA) by providing an intuitive dashboard to inspect, analyze, and understand datasets before building Machine Learning models.

Unlike traditional dashboards, DataMind Studio focuses on dataset quality, statistical summaries, visualization, AI recommendations, and interactive analytics—all in a clean and modern user interface.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/yourusername/DataMind-Studio.git
```

---

## Navigate to Project

```bash
cd DataMind-Studio
```

---

## Run the Project

If using VS Code

Install **Live Server** extension and click

```
Open with Live Server
```

or run

```bash
python -m http.server 8000
```

Visit

```
http://localhost:8000/
```
